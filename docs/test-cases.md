# 테스트 케이스 목록 (v1)

요청 기능 중심. 분류: **L** 로직 · **E** 예외 처리 · **B** 경계 조건(edge case).
각 TC ID는 `tests/` 의 테스트 함수 이름에 들어간다 (예: `test_GEO_03_...`).
자동화 불가 항목은 맨 아래 수동 체크리스트.
