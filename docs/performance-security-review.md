## 3. 남은 권장 사항

- **코드 서명**: 서명하지 않은 exe라 SmartScreen 경고가 뜨고, 일부 백신이 오탐할 수 있습니다. 배포 규모가 커지면 코드 서명 인증서(예: Azure Trusted Signing)를 권장합니다.
- **사용자 폴더 설치의 한계**: 같은 사용자 권한으로 실행되는 악성 프로그램은 설치 폴더의 파일을 바꿀 수 있습니다. 관리자 권한 없이 설치하는 방식에서는 공통적인 한계이며, 서명을 적용하면 변조를 감지할 수 있습니다.
- **OCR 모델 상주 메모리**: 빠른 인식을 위해 한국어 모델(약 100 MB)을 메모리에 올려 둡니다. 메모리가 아주 적은 PC를 위해, 필요하면 "사용하지 않을 때 모델 내리기" 옵션을 추가할 수 있습니다.

### 바꾼 것
- 요약 모델 스레드: 4 → 코어 절반(최대 8). 글 읽는 단계(prefill)가 빨라짐(긴 글 9.8 → 6.6초). 번역은 4가 8보다 빨라서 그대로.
- 같은 문장 제거: OCR·스크롤 캡처에서 겹친 문장(8자 이상)은 한 번만 모델에 보냄. 짧은 줄("예.", "표 1")은 그대로.
- 조기 멈춤: 모델이 원문을 베끼기 시작하거나(<text>), 같은 줄·같은 글자·짧은 구절을 반복하거나, 글머리표 8개·12줄을 넘기면 그 자리에서 멈춤. 베끼기만 했으면 지시를 글 뒤에 두고 한 번 더 요청.
- 최대 생성 길이 320 → 256 토큰 (3~5개 글머리표는 80~180 토큰).
- 최근 결과 20개를 메모리에만 보관(디스크에 쓰지 않음, 앱 종료 시 사라짐). 클라우드 실패로 오프라인 처리한 결과는 보관하지 않아 다음에 다시 클라우드를 시도.
- 요약의 `**` 굵게 표시 기호 제거 (화면은 일반 글자).
