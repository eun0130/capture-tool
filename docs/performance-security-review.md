## 3. 남은 권장 사항

- **코드 서명**: 서명하지 않은 exe라 SmartScreen 경고가 뜨고, 일부 백신이 오탐할 수 있습니다. 배포 규모가 커지면 코드 서명 인증서(예: Azure Trusted Signing)를 권장합니다.
- **사용자 폴더 설치의 한계**: 같은 사용자 권한으로 실행되는 악성 프로그램은 설치 폴더의 파일을 바꿀 수 있습니다. 관리자 권한 없이 설치하는 방식에서는 공통적인 한계이며, 서명을 적용하면 변조를 감지할 수 있습니다.
- **OCR 모델 상주 메모리**: 빠른 인식을 위해 한국어 모델(약 100 MB)을 메모리에 올려 둡니다. 메모리가 아주 적은 PC를 위해, 필요하면 "사용하지 않을 때 모델 내리기" 옵션을 추가할 수 있습니다.

| 항목 | 조치 |
|---|---|
| CPU 부하 | 오프라인 번역·요약 모두 스레드 4개로 제한(코어 전부 사용 안 함). 한 번에 한 작업만. |
| 메모리 | 요약 모델은 처음 쓸 때만 불러오고, 90초 동안 안 쓰면 내림(실측: 내린 뒤 메모리 반환 확인). 입력 2만 자 상한. |
| 모델 다운로드 | HTTPS, 고정 버전·SHA-256 지문 확인 후에만 설치. 반쯤 받은 파일은 설치로 보지 않음. zip 경로 탈출 거부. 디스크 공간 확인. |
| 외부 전송 | 기본은 오프라인. Gemini는 사용자가 직접 키를 넣고, 처음 쓸 때 동의(무료 등급은 사람이 볼 수 있음을 안내)해야 전송. 전송 전 전화·이메일·주민번호·카드번호 가림. |
| 키 보관 | Windows DPAPI(사용자 계정)로 암호화해 settings.json에 저장. URL·로그·오류 메시지에 키가 나오지 않음(요청 헤더로만 전송). |
| 프롬프트 주입 | 인식한 글은 `<text>` 안의 자료로만 다루라고 지시. 결과는 화면에 글자로만 표시(실행·링크 열기 없음). |
| 네트워크 멈춤 | OCR 부품이 인터넷 기능을 건드리지 않게 함(v0.3.7). Gemini 요청 30초 제한, 실패 시 오프라인으로 대체. |
