## 캡처 도구 v0.10.3 (작성 중)

### 고침 — 캡처 화면에서 Esc 가 안 먹던 문제 (Windows)
- Windows Terminal(herdr 등) 같은 프로그램을 쓰다가 Alt + ~ 로 캡처를 시작하면, 키보드가 그 프로그램에 남아 Esc 로 캡처 화면을 닫을 수 없던 문제를 고쳤습니다. 이제 키보드가 어디 있든 Esc 한 번이면 닫힙니다.

### 고침 — 회사 PC에서 요약이 "genai_config.json" 오류로 안 되던 문제 (Windows)
- Windows 사용자 이름에 한글이 있으면 요약 모델을 열지 못하던 문제를 고쳤습니다. 이미 받은 모델 그대로 쓰며 다시 받을 필요가 없습니다.
