## 캡처 도구 v0.10.3

### 고침 — 캡처 화면에서 Esc 가 안 먹던 문제 (Windows)
- Windows Terminal(herdr 등) 같은 프로그램을 쓰다가 Alt + ~ 로 캡처를 시작하면, 키보드가 그 프로그램에 남아 Esc 로 캡처 화면을 닫을 수 없던 문제를 고쳤습니다. 이제 키보드가 어디 있든 Esc 한 번이면 닫힙니다.

### 요약이 "genai_config.json" 오류로 안 될 때 원인을 알려 줌 (Windows)
- 요약 모델이 열리지 않으면 모델 파일을 검사해, 파일이 없는지 / 보안 프로그램이 읽기를 막는지 / 받은 뒤 바뀌었는지(문서 암호화 등)를 안내에 적습니다. 회사 보안 프로그램 때문이면 안내대로 보안 담당자에게 모델 폴더 예외를 요청하면 됩니다.
