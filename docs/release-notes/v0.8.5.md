## 캡처 도구 v0.8.5

### 표 읽기 — 처음 보는 표에서도 맞게 (검증 결과 반영)
- 띄어쓰기를 표마다 글꼴에 맞춰 자동으로 판단합니다(단어 안 간격보다 확실히 넓은 빈칸만 띄어쓰기).
- 줄바꿈된 칸: 단어 중간에서 잘린 줄은 붙이고, 혼자 쓰는 한 글자 단어("안 됨"의 "안")는 띄웁니다.
- 칸이 줄바꿈되는 문서·웹 표에서 이웃한 두 칸의 글이 한 칸으로 붙던 문제를 고쳤습니다.
- 개발 중에 본 적 없는 표 48개(터미널·문서, 밝은/어두운 화면, 1~4열, 줄바꿈, 화살표, 색 글자)를 자동으로 만들어 매 배포마다 시험합니다: 행·열 구조 100%, 글자 약 99% 정확.

- 앞 칸 글이 다음 칸 바로 앞까지 차 있어도(빈 틈이 없어도) 열을 정확히 나눕니다: 여러 줄이 같은 위치에서 시작하는 곳을 열의 시작으로 봅니다.

(v0.8.3·v0.8.4는 빌드 서버의 시험에서 멈춰 배포되지 않았고, 그 시험이 찾아낸 문제까지 고쳐 v0.8.5로 냅니다.)

### 설치 / 업데이트
