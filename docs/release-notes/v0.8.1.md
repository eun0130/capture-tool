## 캡처 도구 v0.8.1

### 글자로 그린 표 — 남은 오차 정리
- 인식 모델이 모르는 **↔** 화살표를 모양으로 알아봐 되살립니다(→, ←도).
- 따옴표 옆 띄어쓰기를 바로잡았습니다: `"관행"으로만`.
- 표 선 색을 화면에서 보이는 회색 그대로 씁니다.
- 캡처 가장자리에 **반쯤 잘린 글자**가 있으면 "일부가 틀릴 수 있습니다. 조금 넓게 캡처하면 정확합니다"라고 알려 줍니다(잘린 부분은 그림에 없어 정확히 읽을 수 없습니다).

### 표 → 워드
- 표 버튼의 붙일 곳에 **워드에 넣기**가 생겼습니다(▾ 메뉴, 처음 묻는 창, 미리 보고 고치기 창). 열린 Word 문서의 커서 위치에 고칠 수 있는 표로 들어가고, Word가 꺼져 있거나 문서가 없으면 새 문서에 넣습니다.
- 엑셀·PPT와 같이 **캡처 모양 그대로 / 흰 바탕·검은 글씨**를 고를 수 있고, 열 너비는 캡처 비율대로 쪽 너비에 맞춥니다.
- Word에 못 넣으면 클립보드에 있으니 Ctrl+V 하면 됩니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.1.exe`를 내려받아 실행합니다.
