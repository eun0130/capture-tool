## 캡처 도구 v0.8.23

### 새 기능 — 회전 (전체 → 왼쪽 회전 · 오른쪽 회전)
- 캡처(또는 편집 창의 그림)를 90°씩 돌려 편집 창에서 엽니다. 돌린 그림이 바로 복사되고, 텍스트·표·PPT 등 모든 버튼을 그대로 씁니다. 그린 것도 함께 돌아갑니다.

### 문서 사진(카메라로 찍은 계약서 등) 글자 복사 — 세 가지 고침
- **줄 순서 뒤바뀜**(2번·3번이 한 줄로 섞임) 고침. 기울어진 사진의 한 줄이 두 줄로 끊기던 것도 함께(기울기 자동 보정) (BUG-110).
- **◆ 가 → 로** 복사되던 문제 고침 — ◆·■·● 를 모양대로 되돌립니다 (BUG-111).
- **흐린 인쇄 오타** 줄임 — 사진으로 판별되면 2배 키우고 선명하게 한 뒤 읽습니다(건울→건물, 울티슈→물티슈 등) (BUG-112).

### 알려진 한계
- 사진에서 ㅁ/ㅇ 혼동(원상복구항·투입금지항·이울질)은 인식 모델의 한계로 일부 남습니다. 더 가까이·수평으로 찍으면 좋아집니다.
- **사진 속 표**(기울어진·흐린 선)는 격자를 못 찾아 표·도형PPT가 어긋날 수 있습니다. **표** 미리보기에서 나누기 규칙으로 칸을 만들어 주세요. 스캔·화면 캡처 표는 그대로 됩니다.
