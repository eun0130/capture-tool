## 캡처 도구 v0.8.25

### 새 기능 — 배경 지우기 (전체 → 배경 지우기)
- 종이·화면의 바탕을 지우고 **글씨·사인·도장만 투명하게** 남깁니다. 결과는 투명 PNG로 복사·저장되어 PPT·워드·그림판에 Ctrl+V 하면 뒤가 비쳐 보입니다.
- 잉크를 **색별 레이어**(검정 글씨, 빨강 도장 …)로 나눠 남길 것을 고릅니다. **지우는 정도**(1~4)로 흐린 선을 살리거나 진한 것만 남깁니다. 체크무늬 미리 보기.
- 사진의 고르지 않은 조명도 바탕으로 처리합니다. **올가미(K)** 로 사인만 따낸 뒤 쓰면 가장 깔끔합니다. 표의 선처럼 진한 것은 남을 수 있으니 올가미로 빼 주세요.

### 새 기능 — 그린 것 다시 고치기
- 아무 도구에서나 그린 것을 **두 번 클릭**하면 선택됩니다(선택 도구로 바뀜). 끌어서 옮기고, 색·굵기를 바꾸고, Delete로 지웁니다. 번호도 됩니다.
- **글자를 두 번 클릭**하면 그 자리에서 다시 고칩니다(Enter 적용, Esc 유지). Ctrl+Z 로 한 단계 되돌립니다.

### 고침
- 복사·저장 안내 팝업이 캡처 그림과 도구를 가리던 것(BUG-114): 캡처·막대를 피하는 자리에 나옵니다.
- 캡처 시작 때 나오는 최근 캡처 띠가 캡처할 곳을 가리던 것(BUG-115): 마우스가 아래쪽이면 띠가 위에 나옵니다.
