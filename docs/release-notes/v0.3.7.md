## 캡처 도구 v0.3.7

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 고친 문제
- **텍스트 인식과 프로그램 시작 점검이 멈추던 문제**: 글자 인식 부품이 켜질 때 인터넷 연결 기능(IPv6)을 한 번 확인하는데, 인터넷 뱅킹 보안 프로그램이 설치된 PC에서는 이 확인이 끝나지 않아 **텍스트 기능이 계속 멈춰 있을 수** 있었습니다. 캡처 도구는 인터넷을 쓰지 않으므로 이 확인을 건너뛰게 했습니다.

### v0.3.6의 새 기능 (스크롤 캡처)
- 영역을 고르고 **스크롤**을 누르면 아래로 자동 스크롤하며 긴 그림으로 이어 붙입니다.
- 브라우저 창 전체를 고르고 **스크롤**을 누르면 페이지 처음부터 끝까지 페이지 내용만 찍습니다.
- 캡처 방지가 걸린 창과, 보안 프로그램이 화면 캡처를 막는 경우를 알아보고 알려 줍니다(우회하지 않음).

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.7.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
