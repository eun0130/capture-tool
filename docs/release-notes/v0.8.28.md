## 캡처 도구 v0.8.28

### 버튼 막대 — 끌어서 배치
- 버튼을 **누른 채 끌면** 자리를 옮깁니다. 원래 자리는 흐려지고 놓일 자리에 **파란 선**이 보입니다. 놓으면 그 자리로 가고 지금 장소(집/회사) 배치에 바로 저장됩니다.
- 전체 줄의 버튼을 **첫 줄로 끌어 올리면** 즐겨찾기에 들어가고, 첫 줄 버튼을 **전체 줄로 끌어내리면** 빠져서 제 그룹으로 돌아갑니다. 막대 밖에서 놓거나 Esc면 취소. 복사·전체는 자리 고정.
- 그냥 클릭은 전처럼 실행됩니다. 오른쪽 클릭 메뉴와 설정 → 버튼 막대는 그대로이고, 설정의 즐겨찾기 목록도 끌어서 순서를 바꿉니다. 편집 창의 세로 막대도 같은 방식.

### 회사용 — 메일도 뺌
- 회사용 설치 파일에는 카톡에 이어 **메일**도 없습니다: 버튼, 설정의 메일 항목, 설명서의 메일 장, 보내기 동작 모두 빠집니다.
- 집용에서 장소를 **회사**로 두면 메일·카톡이 기본으로 숨겨집니다.
- 설치된 회사용은 환경 변수로도 집용이 되지 않고(설치본은 빌드 표식만 따름), 카톡·메일 모듈 자체가 번들에서 빠집니다.
