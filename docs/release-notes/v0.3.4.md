## 캡처 도구 v0.3.4

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 고친 문제
- **텍스트 → PPT로 누르면 PowerPoint가 "응답 없음"으로 멈추던 문제**: 일반 화면(특히 어두운 테마)을 엑셀 표로 잘못 알아보고, 수만 칸짜리 글자를 PowerPoint에 넣어서 생긴 문제였습니다.
  - 표 인식을 더 엄격하게 바꿨습니다. 가는 격자선이 있고, 칸이 적당한 크기이며, 칸의 4분의 1 이상에 글자가 있어야 표로 봅니다. 제목 표시줄이나 어두운 배경처럼 채워진 영역은 선으로 보지 않습니다.
  - PowerPoint에는 글자를 최대 5000자까지만 넣습니다. 넘으면 앞부분만 넣고 알려 드리며, 전체 글자는 Ctrl+V로 붙여넣을 수 있습니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.4.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
