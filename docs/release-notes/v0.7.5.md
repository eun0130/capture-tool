## 캡처 도구 v0.7.5

### 사용 설명서에 그림 추가
- 그림이 있으면 이해가 빠른 5곳에만 그림을 넣었습니다: 캡처하기(고른 곳·버튼 막대·그리기 도구), 버튼 막대 전체 펼침, 표 옵션 창, 메일 붙여넣기 도우미, 고정 캡처의 작은 막대.
- 앱의 설명서 창(F1 · 전체 → 도움말 · 트레이 메뉴)과 문서 docs/QUICK_START.md 모두 같은 그림입니다.
- 그림은 실제 앱 화면 부품을 가상 화면 위에 띄워 만들었습니다(개인 화면이 들어가지 않음).

### 고친 문제
- 고정한 캡처에 마우스를 올리면 나오는 작은 막대 뒤로 그림 속 글자가 비쳐 보이던 문제를 고쳤습니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.7.5.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
