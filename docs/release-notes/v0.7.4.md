## 캡처 도구 v0.7.4

### 처음 쓰는 분을 위한 사용 설명서 (팝업)
- 따라하기 설명서를 앱 안에서 바로 볼 수 있습니다: 캡처 중 **F1**, 버튼 막대의 **전체 → 도움말**, 트레이 메뉴의 **사용 설명서 (따라하기)**.
- 13개 장(캡처하기, 버튼 막대, 그리기, 표, 글자·번역·요약, PPT, 메일, 카톡, 검색, 고정, 스크롤, 저장·링크·설정, 잘 안 될 때)을 왼쪽 목록에서 고르거나 **이전 / 다음**으로 넘기며 봅니다.
- 업데이트 후 처음 켤 때 한 번 자동으로 열립니다.
- 같은 내용이 문서 **docs/QUICK_START.md**에도 있습니다(앱과 문서가 항상 같도록 시험으로 확인).
