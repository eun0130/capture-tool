## 캡처 도구 v0.3.3

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 고친 문제
- **PowerPoint "응답 없음"으로 멈추던 문제**: PowerPoint 화면을 원격으로 조작(창 활성화, 붙여넣기 명령)하던 방식을 없애고 문서에 직접 넣도록 바꿨습니다. 모든 작업에 15초 제한을 두어, PowerPoint가 응답하지 않으면 알려 주고 캡처 도구는 멈추지 않습니다. 보내는 중에 다시 눌러도 중복으로 보내지 않습니다.
- **텍스트 모드에서 복사 → PPT로 → Ctrl+V 하면 글자가 붙지 않던 문제**: 이제 텍스트 모드에서 PPT로를 누르면 복사한 글자가 텍스트 상자로 들어가고, 클립보드의 글자도 그대로 남습니다.

### 바뀐 점
- **PPT로 = 캡처한 그대로**: 그린 것까지 포함한 그림(화면 크기 그대로, 슬라이드보다 크면 맞춰 줄임), 텍스트 모드에서는 글자.
- **도형PPT** 아이콘 추가: 도형을 알아봐서 PowerPoint에서 고칠 수 있는 도형으로 넣는 기능은 이 아이콘으로 옮겼습니다.
- **글씨체 목록**: 맨 위에 자주 쓰는 한글 글꼴(맑은 고딕, 나눔고딕, 나눔명조, 본고딕, 굴림, 돋움, 바탕, 궁서, 함초롬 등 — 설치된 것만)을 각자의 모양으로 보여 주고, 아래에 나머지 글꼴을 가나다·ABC 순으로 보여 줍니다. 이름 일부를 입력하면 찾아 줍니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.3.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
