## 캡처 도구 v0.8.15

### 텍스트 복사
- **줄바꿈 없이**: 텍스트 모드 버튼 줄에 추가. 여러 줄을 한 문단으로 이어 붙여 복사합니다(엑셀 한 칸, 메모·검색창에 붙일 때 편함).
- "화면에 보이는 대로"(색·배경 유지)는 기존 **서식 유지** 버튼이 그대로 합니다.

### 도형PPT
- **글자를 하나의 상자로 합쳐서**: 도형PPT 버튼의 ▾ 메뉴에 추가. 배너·문단처럼 흩어진 글자를 한 개의 텍스트 상자로 넣습니다(줄 순서·색·왼쪽 정렬 유지). 기존 "도형 + 글자 그대로"는 기본으로 남습니다.

### 점검
- 텍스트 복사 띄어쓰기를 여러 글꼴·크기로 자동 점검(유지 98% 수준). 바탕체처럼 좁은 글꼴에서 간혹 붙는 경우는 글자 인식 모델 한계입니다.

### 알려진 한계
- 굵은 색 글자에서 가는 대문자 **I**가 누락될 수 있습니다(예: "AI를" → "A를"). 글자 인식 모델의 한계로, 조금 넓게/크게 캡처하면 나아집니다.
