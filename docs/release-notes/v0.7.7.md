## 캡처 도구 v0.7.7

### 웹 화면을 도형PPT로 — 원래 모양에 가깝게
- 입력칸·버튼은 **상자**로, 체크 상자와 동그라미 선택 단추(라디오)도 **각각 도형**으로 들어갑니다.
- 글자는 **원래 자리**에 따로 들어갑니다(판 가운데로 몰리지 않음). 버튼 글자가 두 줄로 깨지지 않습니다.
- 드롭다운 화살표·아이콘이 "V", "O" 같은 엉뚱한 글자로 들어가지 않습니다.
- 버튼 색을 정확히 읽습니다(글자색과 섞이지 않음).

### 구글 렌즈
- 그림으로 찾기를 누르면 구글 "이미지로 검색" 창이 열리고 **캡처가 저절로 붙어** 바로 찾습니다. 다른 창이 앞에 있으면 아무것도 누르지 않으니, 그때는 직접 Ctrl+V 하세요.
