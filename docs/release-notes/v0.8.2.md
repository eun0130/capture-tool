## 캡처 도구 v0.8.2

### 표 붙여넣기 — 더 정확하게
- **줄바꿈된 칸**(카톡·웹·터미널 표)이 줄마다 다른 행으로 나뉘던 문제: 행 사이 구분선 사이의 줄을 한 행으로 묶고, 칸 안의 글을 자연스럽게 이어 붙입니다(셀 병합 수작업이 필요 없음).
- 터미널 표의 **띄어쓰기**가 사라지던 문제, **↔** 화살표, 문장 끝 마침표를 바로잡았습니다.
- 다른 **색**으로 쓴 단어(예: 연보라 글씨)는 엑셀·워드·PPT에서도 그 색 그대로 들어갑니다.
- 오른쪽이 잘려 **한 열만 보이는 표**도 표로 알아봅니다.

### 표 버튼 — 누르면 바로 결과가 보이게
- 표를 엑셀·PPT·워드로 보내면 **캡처 화면이 닫히고** 결과(PowerPoint 등)가 바로 앞에 보입니다. 전에는 캡처 화면이 앞을 가려 Esc를 눌러야 했습니다.
- 도형PPT를 표 모양 캡처에 쓰면 흩어진 글상자 대신 **PowerPoint 표**로 들어갑니다.

### 자동저장 파일 이름
- `Capture_` 없이 날짜부터 시작합니다: `261004_143012.png`. (직접 바꾼 이름 규칙은 그대로)
