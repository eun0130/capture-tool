## 캡처 도구 v0.10.0

### 새 기능 — 맥(Mac)에서도 (집용, Apple Silicon)
- `CaptureTool-0.10.0-mac.dmg`를 열고 CaptureTool을 **응용 프로그램** 폴더로 끌어 넣습니다. 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 앱을 **우클릭 > 열기** 하세요(서명·공증 없음).
- 처음 실행 때 **화면 기록** 권한을 켜야 합니다(시스템 설정 > 개인정보 보호 및 보안 > 화면 기록). 스크롤 캡처는 **손쉬운 사용** 권한도 필요합니다.
- 기본 단축키 **Shift + Cmd + 2** (설정에서 바꿀 수 있음). 메뉴 막대 아이콘에서도 캡처·설정·종료.
- 되는 것: 영역·창·전체·스크롤 캡처, 그리기·편집, 복사·저장·PDF·인쇄, 글자·표 인식 복사, 메일(mailto)·웹 검색, 캡처 찾기·모양으로, 번역·요약.
- 맥에 없는 것: PPT 도형/Excel/Word로 바로 보내기, 카카오톡, Google Lens, DRM 감지. 그림·표는 클립보드에 있으니 Keynote·PowerPoint·Numbers에 **Cmd + V** 하세요.
- 설정·카탈로그는 `~/Library/Application Support/CaptureTool`, 모델 팩은 그 아래 `models`.

### Windows
- 동작 변화 없음. 내부 구조만 OS별 백엔드로 나뉨(테스트 전부 통과).

### 설치 / 업데이트
Windows: 트레이 메뉴 **새 버전 0.10.0 설치…** 또는 https://github.com/eun0130/capture_dist/releases 의 `CaptureTool-Setup-0.10.0.exe`(회사용은 capture_work의 `CaptureTool-Work-Setup-0.10.0.exe`). 맥: 같은 곳의 `CaptureTool-0.10.0-mac.dmg`; 다음 버전부터는 메뉴 막대의 업데이트 확인이 dmg를 받아 열어 줍니다.
