## 캡처 도구 v0.8.14

### 새 기능: 네모로 자르기
- 그리기 도구 줄의 **자르기** (단축키 **X**): 남길 부분을 네모로 끌면 그 크기로 잘립니다. 복사·저장·PPT·메일·텍스트 모두 자른 부분만.
- 일반 캡처, 스크롤 캡처 편집 창, 다시 연 그림 모두에서 됩니다. Ctrl+Z 로 되돌립니다.

### 고친 것
- **Confluence에 서식 유지 붙여넣기**: Confluence는 정해진 색만 받아서 색이 사라졌습니다. 이제 Confluence 색 중 가장 가까운 색으로 붙습니다(엑셀·워드·PPT는 원래 색 그대로).
