## 캡처 도구 v0.2.3

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 이번 버전에서 바뀐 점
- 회사 PC에서 **"ai.exe - Bad Image … Fasoo DRM\f_nxa.dll … 0xc0000428"** 창이 뜨는 경우를 안내합니다.
  - 원인: PowerPoint가 켜질 때 실행하는 Office AI 프로그램(ai.exe)과 문서 보안 프로그램(Fasoo DRM)의 충돌입니다. 캡처 도구의 오류가 아니며, PowerPoint를 직접 켜도 똑같이 뜹니다.
  - 캡처 도구가 Fasoo DRM을 자동으로 감지하고, "PPT로"를 처음 쓸 때 원인과 대처법을 한 번 알려 줍니다. OK를 누르면 계속 정상 사용할 수 있습니다.
  - [사용 가이드의 문제 해결](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md#11-문제가-생겼을-때)에 IT 담당자에게 보낼 요청 문구를 넣었습니다.

### 설치 / 업데이트
1. 아래 **Assets**에서 `CaptureTool-Setup-0.2.3.exe`를 내려받아 실행합니다. 이전 버전이 있으면 덮어서 업데이트되고 설정은 유지됩니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.
