## 캡처 도구 v0.11.0

### 새 기능 — 화면 녹화 (집용, Windows·맥)
- 고른 부분을 **동영상(MP4)** 이나 **움짤(GIF)** 로 찍습니다. **Ctrl + Alt + R**(맥: Ctrl + Option + R) 을 누르고 영역을 고르거나, 캡처 아래 막대의 **전체 → 녹화**, 트레이 메뉴 **화면 녹화**.
- **소리**: 마이크와 컴퓨터 소리를 함께 녹음합니다(설정에서 각각 끄기). 녹화 중 조작 막대에서 마이크만 잠시 끌 수 있습니다.
- 3초를 센 뒤 시작하고, 녹화하는 곳은 빨간 테두리로 보입니다. 조작 막대에 걸린 시간·크기·일시정지·끝내기(Esc)가 있습니다. 테두리와 막대는 영상에 찍히지 않고, 마우스 포인터와 클릭 표시는 찍힙니다.
- 끝나면 **결과 창**: 재생해 보고, 파란 손잡이로 앞뒤를 잘라 내고, MP4/GIF를 고른 뒤 **복사**(파일째 — 카톡·메일에 Ctrl+V) · **저장** · **다른 이름 저장**.
- 동영상은 Windows·macOS에 들어 있는 인코더로 만듭니다(H.264 + AAC, 어디서나 재생). 따로 설치할 것은 없습니다.
- 회사용에는 아직 없습니다(회사 보안 정책 확인 뒤).

### 설치 / 업데이트
Windows: 트레이 메뉴 **새 버전 0.11.0 설치…** 또는 https://github.com/eun0130/capture_dist/releases 의 `CaptureTool-Setup-0.11.0.exe`(회사용은 capture_work의 `CaptureTool-Work-Setup-0.11.0.exe`). 맥: 같은 곳의 `CaptureTool-0.11.0-mac.dmg`, 또는 메뉴 막대의 업데이트 확인. 맥은 처음 녹화할 때 마이크 권한을 묻습니다 → **허용**.
