## 캡처 도구 v0.11.0

### 새 기능 — 화면 녹화 (집용, Windows·맥)
- 고른 부분을 **동영상(MP4)** 이나 **움짤(GIF)** 로 찍습니다. **Ctrl + Alt + R**(맥: Ctrl + Option + R) 을 누르고 영역을 고르거나, 캡처 아래 막대의 **전체 → 녹화**, 트레이 메뉴 **화면 녹화**.
- **소리**: 마이크와 컴퓨터 소리를 함께 녹음합니다(설정에서 각각 끄기). 녹화 중 조작 막대에서 마이크만 잠시 끌 수 있습니다.
- 3초를 센 뒤 시작하고, 녹화하는 곳은 빨간 테두리로 보입니다. 조작 막대에 걸린 시간·크기·일시정지·끝내기(Esc)가 있습니다. 테두리와 막대는 영상에 찍히지 않고, 마우스 포인터와 클릭 표시는 찍힙니다.
- 끝나면 **결과 창**: 재생해 보고, 파란 손잡이로 앞뒤를 잘라 내고, MP4/GIF를 고른 뒤 **복사**(파일째 — 카톡·메일에 Ctrl+V) · **저장** · **다른 이름 저장**.
- 동영상은 Windows·macOS에 들어 있는 인코더로 만듭니다(H.264 + AAC, 어디서나 재생). 따로 설치할 것은 없습니다.
- 회사용에는 아직 없습니다(회사 보안 정책 확인 뒤).
- **긴 녹화**: 최대 4시간. 2시간 10분 녹화 시험에서 소리와 화면 차이 0.03초 이내, 소리 끊김 없음(마이크·컴퓨터 소리 장치의 시계가 조금씩 달라도 맞춰 감). 2시간짜리에서도 결과 창이 1초 안에 열리고, 뒤쪽 1분을 잘라 저장하는 데 몇 초.

### 고침 — 도형PPT
- 사진·목차·아이콘 목록이 있는 슬라이드가 통째로 엉뚱한 표가 되어 다른 글이 사라지던 문제. 표는 캡처가 정말 표일 때만 표로, 아니면 도형과 글상자로 그 자리에.
- 큰 글씨(슬라이드)의 'o' 를 라디오 단추로 알아봐 줄이 잘리고 작은 그림 조각이 가득하던 문제.
- **사진은 사진 그대로**: 슬라이드의 사진이 단색 판이나 큰 원으로 바뀌고, 사진 속 무늬가 엉터리 글자("40 10 15" 등)로 들어가던 문제. 사진은 그림으로 뒤에, 사진 위 글은 고칠 수 있는 글상자로 위에.
- 지도·인포그래픽·차트 배경도 그림 한 장으로, 그 위 글자는 글상자로. 격자선 위의 막대그래프 막대가 사라지던 문제.
- 글자가 슬라이드 밖으로 넘치던 문제(상자 폭에 맞춤), 같은 글이 겹쳐 두 번 들어가던 문제, 파란 띠 위 흰 제목이 사라지던 문제, 연회색 판이 진한 회색이 되던 문제.
- 녹화한 영상을 도형PPT로 옮길 때 마우스 포인터·클릭 표시를 지우고 읽습니다.
- 시험: 발표 6개 175장을 원본 PDF와 장마다 대조(글자 옮겨짐 97~98%, 아주 작은 각주 글씨는 화면 크기에서 읽히지 않음).

### 고침 — 맥
- 도형PPT·글자 읽기를 오래 쓰면 가끔 "Python 응용 프로그램이 예기치 않게 종료되었습니다" 창과 함께 꺼지던 문제(그림 처리 부품의 맥 칩 가속 기능 버그를 피함).
