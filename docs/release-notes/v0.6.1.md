## 캡처 도구 v0.6.1

### 바뀐 점
- **PPT로 넣으면 PowerPoint가 맨 앞에 활성화되어 나타납니다.** 예전에는 PowerPoint가 다른 창 뒤에 있어서 제대로 들어갔는지 확인하기 어려웠습니다. 이제 넣은 그림·글자·도형이 선택된 상태로 바로 보이고, PowerPoint가 최소화되어 있어도 다시 띄웁니다.

### 빨라진 점 (이 PC에서 측정)
| 기능 | 전 | 후 |
|---|---|---|
| 스크롤 캡처 (6000픽셀 페이지) | 5.1초 | 3.6초 |
| 긴 그림 글자 인식 (6000픽셀) | 1.9초 | 0.8초 |
| 화면 글자 인식 (14줄) | 0.46초 | 0.35초 |
| 텍스트 모드 후 첫 요약 | 5.2초 | 3.5초 |

- 스크롤 캡처: 정해진 시간만큼 기다리던 것을, 화면이 멈추는 즉시 다음으로 넘어가도록 바꿨습니다.
- 글자 인식: PC 코어 수에 맞춰 더 많이 나눠 처리하고(코어의 절반까지만), 긴 그림의 빈 부분은 건너뜁니다.
- 요약·번역: 텍스트 모드를 열면 모델을 미리 준비합니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.6.1.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
