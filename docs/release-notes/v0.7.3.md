## 캡처 도구 v0.7.3

### 고친 문제
- **네이버 메일로 보낼 때 받는 사람이 비어 있던 문제**: 이제 네이버 메일 쓰기 창이 **받는 사람·제목이 채워진 채로** 열립니다(로그인 상태에서 확인해 주신 형식). 받는 사람을 채울 수 없는 다른 메일 서비스는 받는 사람이 이미 복사된 상태로 열려, 받는 사람 칸에서 바로 Ctrl+V 하면 됩니다.

### 표 복사 옵션
- **표**를 처음 누르면 **엑셀로 복사 / PPT에 넣기**와 **캡처 모양 그대로 / 흰 바탕·검은 글씨**를 고릅니다. "다음부터 이 설정으로 바로"를 켜면 다음부터 한 번에.
- 표 버튼 옆 **▾** 메뉴: 붙일 곳·모양 바꾸기, **미리 보고 고치기**(표 모양이어도 칸을 직접 고친 뒤 붙이기), 매번 묻기 켜고 끄기.
- 흰 바탕·검은 글씨는 선이 있는 깔끔한 표(굵은 머리글)로 엑셀·PPT에 들어갑니다.

### 품질 관리
- 버그 기록부 BUG-069, 회귀 테스트 추가. 시험 중에 확인 창이 떠서 시험이 멈추는 일이 없도록 공통 안전장치를 넣었습니다.
