## 캡처 도구 v0.8.8

### 다시 캡처하지 않고 다시 쓰기
- **최근 캡처 줄**: 캡처를 시작하면 화면 아래에 자동저장한 최근 캡처 8장이 보입니다. 하나를 누르면 캡처할 때와 같은 버튼(표·텍스트·도형PPT·메일·고정…)으로 바로 씁니다. 다시 저장되지는 않습니다. 영역을 고르기 시작하면 줄은 사라지고, 설정에서 끌 수 있습니다.
- **아무 그림 파일 열기**: 그 줄이나 열린 편집 창에 그림 파일을 끌어다 놓기, 파일 오른쪽 클릭 → **보내기 → 캡처 도구**, 바탕 화면 바로가기에 끌어다 놓기, 트레이 메뉴 **이미지 열기…**.
- 그림 파일이 아니거나 너무 큰 파일은 열지 않고 알려 줍니다.

### 표 → 엑셀 (v0.8.7)
- 엑셀이 닫혀 있으면 엑셀을 열어 새 문서의 A1 칸에 바로 붙입니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.8.exe`를 내려받아 실행합니다. 사용 설명서에 "12. 저장한 캡처 · 그림 파일 다시 쓰기"가 추가되었습니다.
