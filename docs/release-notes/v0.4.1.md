## 캡처 도구 v0.4.1

### 고친 문제
- **요약·번역 결과 창에서 PPT로를 눌러도 반응이 없던 문제**: 실제로는 PowerPoint에 들어가고 있었지만, 캡처 화면이 앞을 가리고 완료 알림도 보이지 않아 아무 일도 없는 것처럼 보였습니다(여러 번 누르면 슬라이드가 여러 장 생김).
  - 이제 결과 창에 "PowerPoint에 넣는 중…" → "PowerPoint에 넣었습니다 (새 슬라이드)"가 보이고, 넣는 동안 버튼이 잠겨 두 번 들어가지 않습니다.
  - 성공하면 캡처 화면과 결과 창이 닫혀 PowerPoint의 새 슬라이드가 바로 보입니다. 실패하면 결과 창에 이유를 보여 주고 다시 누를 수 있습니다.
- **인식된 텍스트 창에서 표로 복사를 눌러도 반응이 없던 문제**: 복사는 되고 있었지만 확인 표시가 없었습니다. 이제 창 안에 "표 3행×2열로 복사했습니다"처럼 보입니다. 전체 복사·선택 부분 복사도 같습니다.
- **알림이 안 보이던 문제**: Windows 알림(트레이)이 꺼져 있거나 방해 금지 모드면 "복사했습니다" 같은 알림이 보이지 않았습니다. 이제 화면 아래쪽에 3초 동안 직접 표시합니다(캡처 사진에는 찍히지 않음).

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.4.1.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
