## 캡처 도구 v0.7.2

### 고친 문제
- **한글 표 속 영문이 깨지던 문제**: "신고·검토 UI"가 "ü"로, "GitHub·CI"가 "cI"·"cl"로, 작게 찍으면 "GitHub"가 "Gi채ub"로 읽히던 것을 고쳤습니다. 한글 줄 안의 영문 부분만 영문 인식으로 다시 읽고(한글 부분은 그대로), "·" 같은 기호는 원래대로 둡니다.
- **표를 엑셀에 붙이면 행 높이가 3~4배로 커지던 문제**: 긴 칸이 좁은 엑셀 칸에서 줄바꿈되던 것을 막아 한 줄로 붙습니다(실제 엑셀에서 모든 행 17.5pt 확인).

### 품질 관리
- 버그 기록부 BUG-067, BUG-068과 회귀 테스트 추가(실제 캡처 이미지로 배율 3가지 확인, 실제 엑셀 행 높이 확인).

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.7.2.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
