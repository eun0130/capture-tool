## 캡처 도구 v0.7.9

### 영어 글자 인식 — 정확하게
- 영어 문단에서 글자가 겹쳐 나오던 문제("e elite", "a advisor", "h t how")를 고쳤습니다.
- 대문자 I / 소문자 l 혼동("so l can", "l'm", "Al")을 고쳤습니다.
- 영어·유럽 언어 줄은 더 최신 인식 모델(PP-OCRv6)로 다시 읽고, 작은 글씨는 키워서 읽습니다. 여러 글꼴(맑은 고딕, Segoe UI, Arial, Calibri, Times, Consolas, Verdana, Tahoma) 시험에서 틀린 단어가 약 40% 줄었습니다. 한국어 인식은 그대로입니다.

### 도형PPT — 원본에 더 가깝게
- 화면 속 **표가 진짜 PowerPoint 표**로 들어갑니다(칸 너비·높이, 머리글 색, 선 색, 합친 칸 그대로, 바로 고칠 수 있음). PowerPoint로 바로 보낼 때 적용되며, 클립보드 복사만 할 때는 칸마다 사각형으로 들어갑니다.
- 도형으로 그리기 어려운 **아이콘**(달력, 드롭다운 화살표, 문서 아이콘)과 빠진 기호("(", "-", "~")는 그 부분만 **작은 그림**으로 제자리에 들어갑니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.7.9.exe`를 내려받아 실행합니다. 설정은 유지됩니다. (설치 파일이 약 13MB 커졌습니다.)
