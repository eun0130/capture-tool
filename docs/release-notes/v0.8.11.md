## 캡처 도구 v0.8.11

### 새 기능: 글자를 서식 그대로 복사
- **텍스트** 를 누르면 글자와 함께 **글자색·배경색·굵기·들여쓰기·고정폭 여부**까지 복사됩니다 (텍스트 줄의 **서식 유지** 로 켜고 끕니다).
- **엑셀**: 한 줄에 한 칸씩, 배경색과 글자색이 그대로 들어갑니다 (수식처럼 보이는 글도 글자로만).
- **워드 · 웹 편집기(Confluence 등)**: Ctrl+V 하면 색과 배경이 있는 글로 붙습니다.
- **파워포인트**: 텍스트 모드에서 **PPT** 버튼을 누르면 같은 모습의 글상자 하나로 들어갑니다.
- 메모장 같은 곳에는 예전과 같은 글자만 붙습니다.
- 읽지 못하던 ● · └ 같은 기호도 글자로 되살립니다.

### 알려 둘 점
- 파워포인트에 Ctrl+V 로 붙이면 파워포인트가 서식을 버립니다. **PPT** 버튼을 쓰세요.
- 굵은 글씨는 뚜렷할 때만 굵게 표시합니다. 색 이모티콘(그림 문자)은 글자로 옮기지 못합니다.
- 글자를 끌어서 일부만 고른 복사는 글자만 복사됩니다.
- Confluence는 직접 붙여 확인하지 못했습니다(표준 HTML로 만들었습니다).
