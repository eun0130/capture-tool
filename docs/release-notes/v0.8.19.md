## 캡처 도구 v0.8.19

### 새 기능 — 테두리 · 음영 (전체 → 테두리)
- 캡처 둘레에 **테두리**와 **그림자(음영)** 를 넣어 깔끔하게 만듭니다.
- **굵기**: 없음 · 얇게 · 보통 · 두껍게.
- **색**: 흰색 · 검정 · 회색 · 파랑 · 빨강, 또는 **색 선택…** 으로 원하는 색 지정.
- **음영**: 체크하면 캡처 뒤에 부드러운 그림자가 생겨 떠 있는 느낌.
- 원본과 결과를 **나란히 미리 보고** [이대로 복사·저장] 하면 그 모양으로 복사됩니다(자동저장이 켜져 있으면 파일로도).
- 마지막에 고른 굵기·색·음영을 기억합니다.

### 알려진 한계 (이전과 동일)
- 꽉 찬 삼각형 안의 나눔선, 굵은 색 글자의 가는 대문자 I(예: "AI를"→"A를")는 글자/모양 인식 모델의 한계입니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.19.exe`를 내려받아 실행합니다.
