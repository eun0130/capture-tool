## 캡처 도구 v0.6.4

### 고친 문제
- **요약 → PPT로를 눌러도 아무 반응이 없던 문제**: 텍스트 화면이 열리면서 AI 모델을 미리 불러오는 동안 요약을 누르면 "하는 중입니다"로 거절되어 결과가 비어 있었습니다. 이제 불러오기가 끝날 때까지 기다렸다가 요약하고, PPT로도 정상으로 들어갑니다.
- **텍스트 바로 인식 단축키**에서 캡처 안에 상자 같은 도형이 있으면 복사가 실패하던 문제, 표가 인식되지 않던 문제를 고쳤습니다.

### 엑셀 표 캡처 → 표로 복사가 더 정확해졌습니다
- 머리글에 **색을 채운 표**(전에는 위쪽 행이 사라짐), **격자선을 끈 표**(전에는 칸이 뭉침), 엑셀의 **A B C / 1 2 3 머리글을 같이 찍은 경우**도 칸 그대로 복사합니다. 실제 엑셀 화면 8가지에서 30칸 모두 정확.
- 칸 테두리를 글자 "|"로 잘못 읽던 것, 한 칸 안의 단어 순서가 바뀌던 것을 고쳤습니다.
- 엑셀에 붙여넣을 때 `007`의 0이 사라지지 않고, `=SUM(...)`처럼 보이는 글자는 **수식으로 실행되지 않습니다**.

### AI 답변의 표 모양 → 엑셀·파워포인트 표로
- 번역·요약 결과가 표 모양(`|` 칸, 탭, 칸 맞춤, "항목: 값" 줄)이면 **표로 복사** 버튼이 켜지고, 엑셀·파워포인트에 붙여넣으면 칸이 나뉜 표가 됩니다.
- **PPT로**는 파워포인트 **진짜 표**(칸마다 편집 가능)로 넣습니다. 슬라이드에 들어가기엔 너무 큰 표는 글로 넣습니다.

### 캡처한 도형을 모양·색 그대로 파워포인트 도형으로
- 글자 **색·크기·굵게**를 화면에서 읽어 그대로 넣습니다(전에는 모두 검정 14pt).
- **마름모**를 알아봅니다. 테두리 없는 색 도형에 테두리가 생기던 문제를 고쳤습니다.
- 도형 밖의 제목·설명 글자는 **글상자**로 들어갑니다(전에는 빠짐).
- 진한 색 도형 안의 글자를 놓치면 그 도형만 다시 읽습니다(놓친 글자 획이 작은 도형 조각으로 들어가던 문제 해결).
- 실제 파워포인트에서 확인: 도형 7종의 채우기·테두리·글자색·글자 크기·굵게가 원본과 같게 하나씩 편집 가능한 도형으로 들어감.
