## 캡처 도구 v0.8.22

### 개인정보 가림 — 왜 `*`로 붙는지 알려 줍니다 (BUG-109)
- 주민번호·전화번호·이메일·카드번호는 **개인정보 자동 가림**(기본 켜짐) 때문에 `*`로 붙습니다. 전에는 아무 말 없이 가려져 비밀번호처럼 보였습니다.
- 이제 복사할 때마다 알림에 **무엇을 몇 건 가렸는지**와 **끄는 법**이 나옵니다(텍스트·한 줄·선택 부분·표 복사 모두).
- 텍스트 창의 **개인정보 자동 가림** 체크를 끄면 **기억**되어 다음부터 숫자 그대로 붙습니다(설정에서도 바꿀 수 있음).
