## 캡처 도구 v0.4.0

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 새 기능 — 무료 AI 번역·요약
- **텍스트** 모드 아래 막대(와 텍스트 창)에 **번역**·**요약** 버튼이 생겼습니다. 드래그한 부분만 할 수도 있습니다.
- **번역**: 설치하자마자 **오프라인·무료**로 한국어↔영어가 됩니다. 일본어·중국어·프랑스어·스페인어·독일어는 처음 쓸 때 한 번 받습니다.
- **요약**: 핵심을 3~5줄로 정리합니다. 기본은 **오프라인 AI**(처음 한 번 약 1.4GB 받기, 글이 PC 밖으로 나가지 않음)입니다.
- **Gemini 무료 키(선택)**: 설정 → AI에서 **무료 키 설정 안내**를 따라 1분이면 넣을 수 있습니다(키 발급 페이지에서 복사만 하면 자동 인식). 넣으면 요약이 1~3초로 빨라지고, 원하면 번역도 더 자연스러워집니다.
  - 글이 Google로 전송되고, 무료 등급에서는 사람이 검토할 수 있어 처음 쓸 때 동의를 받습니다. 개인정보(전화·이메일·주민번호·카드번호)는 보내기 전에 가립니다.
  - 한도 초과·인터넷 끊김이면 자동으로 오프라인으로 처리합니다. 키는 Windows 계정으로 암호화해 저장합니다.

### 고친 문제
- **스크롤 캡처가 중간에 "이어 붙일 곳을 찾지 못함"으로 멈추던 문제**: 화면 배율이 125%·150%일 때 스크롤 위치에 따라 글자 가장자리가 조금씩 다르게 그려지는 경우, 그리고 스크롤 중에 알림 막대가 잠깐 떠서 일부를 가리는 경우에도 이어 붙입니다.
- 큰 글씨를 텍스트로 인식할 때 **단어마다 줄이 나뉘던** 문제: 같은 줄의 단어는 한 줄로 복사됩니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.4.0.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다. (한↔영 번역 모델이 들어 있어 설치 파일이 커졌습니다.)
