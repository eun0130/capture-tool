## 캡처 도구 v0.5.0

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 새 기능
- **창 하나를 통째로 (제목줄 클릭)**: 캡처 중에 드래그 대신 창의 제목줄(또는 창 위)을 클릭하면 그 창 전체가 선택됩니다. **두 모니터에 걸친 창, 화면 밖으로 나간 창, 다른 창에 가려진 창도 창 전체가 한 장으로** 찍힙니다. 마우스를 올리면 무엇이 찍힐지 안내가 보이고, 처음 세 번은 사용법 팁이 나옵니다.
- **자동 저장**: 설정이나 트레이 메뉴에서 켜 두면 캡처를 끝낼 때마다(복사·PPT·고정·텍스트 등 무엇을 하든) 저장 폴더에 자동 저장합니다. 아무것도 안 하고 Esc로 닫으면 저장하지 않습니다.
- **링크**: 오른쪽 아이콘의 **링크** →
  - **파일 링크**: 저장한 파일 위치를 복사 (인터넷 업로드 없음, 공유 폴더면 동료도 열 수 있음)
  - **인터넷 공유 링크**: 누구나 여는 https 주소를 복사. 기본 24시간 뒤 자동 삭제(1시간~3일 선택), 처음 한 번 확인.
- 화면이 작으면 오른쪽 아이콘이 두 줄로 정리됩니다.
