## 캡처 도구 v0.3.0

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 새 기능
- **선 두께 자유롭게**: 팔레트에서 슬라이더나 숫자로 1~60px, 빠른 선택(1·2·4·6·10·20). 키보드 `]` `[` (Shift는 5씩).
- **그린 도형 고치기**: ↖ 선택 도구로 도형을 클릭한 뒤 색·두께·채우기·글자 서식을 바꾸면 바로 적용, Delete로 삭제.
- **글자 서식**: 크기(8~144px), 굵게 `Ctrl+B`, 기울임 `Ctrl+I`, 밑줄 `Ctrl+U`, 취소선 `Ctrl+5`, 크게/작게 `Ctrl+]`/`Ctrl+[`. PPT로 보낼 때도 유지.
- **드래그한 부분만 글자 복사**: 텍스트 아이콘을 누르면 전체가 복사되고, 캡처 위에서 원하는 글자를 드래그하면 그 부분만 바로 복사. "창으로 보기"로 별도 창에서 고를 수도 있고, 창은 Esc로 닫힘.
- **엑셀 표 그대로 복사**: 칸 선이 있는 표를 캡처하면 표 모양 그대로 복사되어 엑셀에 칸별로 붙음(빈 칸 유지).
- **PPT에 같은 크기로**: 150% 등 배율이 있는 화면에서도 도형과 그림이 화면에서 보이던 크기 그대로 들어감(이전에는 1.5배로 커짐).

### 고친 문제
- **Alt + ~ 화면이 작게 보이던 문제**: 배율이 다른 모니터를 함께 쓸 때 정지 화면을 잘못된 모니터 기준으로 그리던 버그 수정.
- 글자를 입력하다 Enter를 누르면 캡처가 복사되고 닫히던 문제 수정(이제 글자만 입력됨, Esc는 입력만 취소).

### 가볍고 안전하게 (성능·보안 점검)
- 메모리 **1,012MB → 203MB**, 스레드 **128개 → 25개** (CPU 코어가 많은 PC 기준), 캡처를 반복해도 메모리가 늘지 않음.
- 아주 복잡한 화면에서도 도형 인식이 3초를 넘지 않음, 로그 파일 최대 약 3MB.
- 인터넷 통신 없음(모델 파일을 몰래 내려받지 않음), 알려진 라이브러리 취약점 0건, 인식한 글자를 로그에 남기지 않음.
- 자세한 내용: [성능·보안 점검 보고서](https://github.com/eun0130/capture-tool/blob/main/docs/performance-security-review.md)
