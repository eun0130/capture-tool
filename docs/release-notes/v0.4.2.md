## 캡처 도구 v0.4.2

### 고친 문제 — PDF 스크롤 캡처가 중간에 멈추던 문제
- **PDF 뷰어(Chrome·Edge)에서 스크롤 캡처가 첫 장이나 그림·구분선이 나오는 중간에서 멈추던 문제**를 고쳤습니다.
  - 원인: PDF 뷰어는 왼쪽 **페이지 썸네일 목록이 움직이지 않고** 문서만 스크롤되는데, 화면 전체가 함께 움직인다고 가정하고 비교해서 이어 붙일 곳을 찾지 못했습니다. (고정된 옆 메뉴가 있는 웹페이지, 틀 고정된 엑셀, 옆 창이 있는 메신저도 같은 문제)
  - 이제 화면을 세로 띠로 나눠 **실제로 스크롤되는 부분만** 찾아 이어 붙이고, 움직이지 않는 썸네일 목록은 결과에서 뺍니다.
- **빈 페이지**처럼 맞춰 볼 무늬가 없는 구간은 스크롤한 만큼 이어서 계속 진행합니다.
- 스크롤 뒤 **페이지를 늦게 그리는** 뷰어는 새로 나타난 부분이 그려질 때까지 잠깐 기다립니다.
- 사진이 확대·축소되며 매번 조금씩 다르게 그려져도, 쪽 번호 표시(3 / 6)가 바뀌어도 이어 붙입니다.

아래 **Assets**에서 `CaptureTool-Setup-0.4.2.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
