## 캡처 도구 v0.7.6

### 고친 문제
- **제목처럼 글자 한 줄을 바짝 캡처하면 글자를 거의 못 읽던 문제** ("매입처별 세금계산서 합계표" → "매 ㅎ"): 읽기 전에 캡처 둘레에 여백을 덧대 끝까지 정확히 읽습니다.
- **구글 그림 검색**: "이미지로 검색" 창이 열린 상태로 열려, 바로 Ctrl+V 하면 됩니다.
- **네이버 그림 검색**은 PC 웹에서 지원되지 않아 메뉴에서 뺐습니다(네이버는 글자 검색만).

### 메일 화면 새 디자인
- **보낼 메일**을 맨 위 버튼으로 바로 고릅니다: **네이버 메일 / Gmail** (다른 메일은 옆 목록).
- 사람마다 **받는 사람 / 참조** 버튼, 고른 사람은 아래에 칩으로 표시(✕로 빼기), 이름 첫 글자 동그라미, 탭(자주·최근·그룹·전체 주소록).
- **주소·그룹 편집** 화면도 같은 디자인으로 정리했습니다.
- **붙여넣기 도우미**: 네이버·Gmail처럼 받는 사람·참조·제목이 이미 채워지는 메일은 "캡처 복사" 하나만 보이고, 칸이 비었을 때만 "다시 복사"를 펼쳐 씁니다. 버튼 이름도 "참조 칸에 붙일 주소 복사"처럼 무엇을 하는지 바로 알 수 있게 바꿨습니다.

아래 **Assets**에서 `CaptureTool-Setup-0.7.6.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
