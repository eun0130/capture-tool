## 캡처 도구 v0.8.31

### 더 빠르게
- **Enter → 복사**: 클립보드에 넣는 시간이 1/3로(4K 기준 PNG 인코딩 327→113ms, 비트맵 45→23ms), 복사 뒤에는 앞에 있던 캡처 창만 먼저 닫고 다른 모니터의 창은 바로 다음 순간에 닫습니다. 자체 점검 copy 105→83ms.
- **글자 모드**: 표 모양 찾기(두 번째 인식)를 백그라운드에서 하므로, 인식 직후 0.5~0.9초 멈추던 것이 없어졌습니다.

- PPT로 보낼 때의 PNG 인코딩도 같은 방식으로 빨라졌습니다.
