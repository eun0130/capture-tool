## 캡처 도구 v0.6.2

### 고친 문제
- **아주 좁은 영역(폭 17픽셀 미만)을 스크롤 캡처하면 오류가 나던 문제**를 고쳤습니다.
- **파일 이름 규칙이 길거나 저장 폴더가 깊으면 저장에 실패하던 문제**: Windows의 경로 길이 한도(260자)를 넘지 않도록 파일 이름을 자동으로 줄입니다.

### 점검 결과
- **메모리 누수 없음**: 기능마다 100번씩(총 500번) 반복해도 메모리·그래픽 자원·핸들·창이 계속 늘지 않습니다.
- **예외·경계 점검**: 무작위 입력 수천 건과 무작위 조작 1,600번에서 오류 0건(위 2건은 이 점검에서 찾아 고침).
- **호환성**: Office가 없는 깨끗한 Windows(Windows 10/11 계열 서버 2022·2025, 1024×768 화면)에서 설치와 자가 점검 통과. 화면 배율 100~200%, 왼쪽·위쪽·세로 모니터, 배율이 다른 모니터 조합에서 정확하게 캡처됩니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.6.2.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
