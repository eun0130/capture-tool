## 캡처 도구 v0.2.1

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 설치
1. 아래 **Assets**에서 `CaptureTool-Setup-0.2.1.exe`를 내려받아 실행합니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. (디지털 서명 전이라 뜨는 안내입니다.)
3. 관리자 권한도, 따로 설치할 것도 없습니다. 인터넷 없이 동작합니다.

### 주요 기능
- **Alt + ~** 로 캡처 (마우스가 있는 모니터가 먼저 멈춤, 약 0.1초)
- 캡처 위에 바로 그리기: 사각형·타원·화살표·곡선·펜·텍스트·번호·형광펜·모자이크, 색상 팔레트
- 캡처 옆 아이콘: **복사 · 저장(위치 선택) · 텍스트(한/영 OCR) · PPT로(편집 가능한 도형으로 붙여넣기) · 고정**
- 텍스트: 부분 복사, 표로 복사(Excel), 개인정보 자동 가림, QR 인식
- 화면에 고정: Esc/✕/더블클릭으로 닫기, 휠 확대, Ctrl+휠 투명도

### 이번 버전에서 바뀐 점
- 기본 단축키가 **Alt + ~** 로 바뀌었습니다. (Win + ~ 는 Windows Terminal과 겹침. 기존 설정은 자동으로 옮겨집니다.)
- 고정한 그림을 **Esc · ✕ 버튼 · 더블클릭**으로 닫을 수 있습니다. 작업 표시줄 메뉴에 "고정 이미지 모두 닫기"가 추가되었습니다.

### 요구 사항
Windows 10(1809 이상) / 11, 64비트 · 약 350MB · "PPT로"는 PowerPoint(Microsoft 365 권장) 필요
