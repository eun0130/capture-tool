## 캡처 도구 v0.8.32

### 새 기능 — 코드로 복사
- 코드 화면(편집기·GitHub·diff)을 찍고 **텍스트** → **코드로 복사** 를 누르면 **줄 번호와 diff의 `+`/`-` 기호를 빼고** 코드만 복사됩니다.
- 들여쓰기는 화면에서 각 줄이 시작하는 위치를 그 화면의 글자 폭으로 재서 되살립니다. “ ” ‘ ’ 같은 따옴표와 전각 기호(＋ ＝ （）)는 코드 글자로 바뀝니다.
- YAML·Markdown의 `- 항목` 은 diff 기호로 보지 않습니다. 번호 없이 이어진 줄(줄바꿈된 긴 줄)은 제자리에 둡니다.

### 더 빠르게
- **캡처 화면 끌기**: 어둡게 한 바탕을 캡처마다 한 번만 만들어 두고 선택 영역만 그 위에 그립니다. 4K 150% 실제 화면에서 한 번 그리기 5.2→3.8ms, 끌기 한 번 8.1→6.4ms.
- **단축키 → 정지 화면**: 이미지 처리 작업 스레드를 4개로 제한해(전엔 코어 수만큼 31개가 놀고 있었음) 자체 점검 overlay 약 90→42ms, 앱 스레드 87→51개.
- **스크롤 캡처(125·150% 배율)**: 프레임을 이어 붙일 자리를 찾는 허용 비교가 183→75ms/프레임(열을 4칸 건너 뛰어 비교; 이어 붙인 결과는 그대로).
- 영문 줄을 두 번째로 읽는 일괄 호출은 재 보니 이득이 없어(1.41초 vs 1.40초) 넣지 않았습니다.
