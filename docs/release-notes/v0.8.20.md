## 캡처 도구 v0.8.20

### 버그 고침 (BUG-106)
- **크기 줄이기·테두리 버튼을 눌러도 아무 반응이 없던** 문제를 고쳤습니다. 대화상자가 전체화면 캡처(항상 위에 뜨는 창) 뒤에 가려져 있었습니다. 이제 버튼을 누르면 캡처를 먼저 닫고 창이 앞에 뜹니다(복사·인쇄와 같은 방식).

### 함께 포함 (v0.8.19)
- **테두리 · 음영**(전체 → 테두리): 캡처 둘레에 테두리(굵기·색)와 그림자를 넣어 복사·저장. 원본/결과 미리보기 제공.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.20.exe`를 내려받아 실행합니다.
