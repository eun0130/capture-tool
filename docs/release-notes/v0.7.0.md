## 캡처 도구 v0.7.0

### 새 버튼 막대
- 버튼이 캡처 **바로 아래 한 줄**로 깔끔하게 나옵니다: 복사 · 자동저장 · 텍스트 · 표 · PPT · 메일 · 카톡 · 고정 · 전체.
- **전체**를 누르면 나머지(다른 이름 저장 · 도형PPT · 스크롤 · 링크 · 저장 폴더)가 둘째 줄로 펼쳐지고, 상태를 기억합니다.
- **자동저장** 버튼이 켜져 있으면 눌린 모양("자동저장 켜짐")으로 보이고, 누를 때마다 켜고 끕니다.
- 아래에 자리가 없으면 위로, 그래도 없으면 캡처 안쪽 아래로 옮기며, 그리기 도구와 겹치지 않습니다.

### 메일로 보내기 (네이버 메일 · Gmail · 네이버웍스 · 다음 · Outlook · 기본 메일 앱 · 회사 메일 주소)
- 주소록(자주·최근·그룹·전체)에서 여러 명을 고르고 받는 사람/참조를 나눕니다. 새 주소도 바로 입력.
- 브라우저의 메일 쓰기 화면을 열고 **붙여넣기 도우미**(받는 사람 · 참조 · 제목 · 캡처를 버튼 하나씩 복사)를 띄웁니다. Gmail은 받는 사람·제목까지 채워져 열립니다.
- 메일은 직접 [보내기]를 눌러 보냅니다. 캡처 도구는 로그인 정보를 다루지 않습니다.
- 붙여넣기가 막힌 환경을 위해 "파일로 저장(첨부용)".
- 주소록은 Windows 사용자마다 암호화해서 이 PC에만 저장, CSV 가져오기(Gmail·네이버·엑셀 cp949)/내보내기(엑셀 수식 실행 방지).

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.7.0.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
