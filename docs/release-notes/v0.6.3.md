## 캡처 도구 v0.6.3

### 오프라인 요약·번역이 더 빨라졌습니다 (Gemini 키 없이)
- **요약이 10~15% 빨라졌습니다** (보고서 9.8 → 8.7초, 공지 6.4 → 5.7초, 영문 5.6 → 4.8초).
- **같은 글을 다시 요약·번역하면 즉시** 결과가 나옵니다 (최근 20개를 메모리에만 기억, 파일로 남기지 않음).
- **OCR·스크롤 캡처에서 겹친 문장**은 한 번만 읽어 더 빠릅니다.
- **요약이 엉뚱하게 길어지던 문제를 고쳤습니다**: 같은 문장이 반복된 글에서 요약 대신 원문을 그대로 베끼며 26초 걸리던 것이 4초 만에 정상 요약됩니다. 같은 말을 되풀이하기 시작하면 바로 멈춥니다.
- 요약에 섞이던 `**` 기호를 없앴습니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.6.3.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
