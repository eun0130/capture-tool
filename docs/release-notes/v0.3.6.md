## 캡처 도구 v0.3.6

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 새 기능 — 스크롤 캡처
- **일반 스크롤 캡처**: 영역을 고르고 오른쪽의 **스크롤**을 누르면, 지금 위치부터 아래로 자동 스크롤하며 한 장의 긴 그림으로 이어 붙입니다.
- **브라우저 페이지 전체**: 캡처 중에 브라우저 창을 클릭해 창 전체를 고르고 **스크롤**을 누르면, 맨 위부터 맨 아래까지 **페이지 내용만**(탭·주소창 제외) 찍습니다. 고정 헤더는 한 번만 나옵니다.
- 끝나면 클립보드에 복사되고, 결과 창에서 저장하거나 PowerPoint로 보낼 수 있습니다. **Esc**로 언제든 멈출 수 있습니다.
- 스크롤 캡처 전용 단축키를 설정할 수 있습니다.

### 보안 화면 확인
- **캡처 방지가 걸린 창**(은행 앱, 보호된 영상 등)이 영역에 있으면 "검게 찍힙니다"라고 알려 줍니다.
- 보안 프로그램이 **화면 캡처 전체를 막아** 한 가지 색으로만 찍히면 "화면 캡처가 막혔습니다"라고 알려 줍니다.
- 캡처 도구는 보안을 우회하지 않습니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.6.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
