## 캡처 도구 v0.7.1

### 표로 붙여넣기 미리보기
- 표 모양이 아닌 글에서 **표**를 누르면, 어떻게 나뉘어 붙을지 **미리보기**가 먼저 뜹니다.
- 칸 나누는 기준(자동 · "항목: 값" · 띄어쓰기 2칸 이상·탭 · 쉼표(숫자 1,250,000은 그대로) · 한 줄 = 한 칸 · 직접 입력), 첫 줄 제목, 글머리표 빼기, 머리글 행 추가.
- 칸을 직접 고치고 줄·칸을 더하거나 뺀 뒤 **표로 복사** 또는 **PPT 표로 넣기**.

### 검색
- 막대의 **검색**: 그림으로 찾기(구글·네이버 이미지 검색 — 검색창에 Ctrl+V), 캡처 속 글자로 찾기(구글·네이버·파파고 번역).
- 그림은 직접 붙여 넣기 전에는 어디에도 올라가지 않습니다.

### 여러 장 고정
- **고정** 버튼에서 띄울 곳 선택: 찍은 자리 / 화면 오른쪽 위에 쌓기 / 다른 모니터.
- 고정 캡처에 마우스를 올리면 작은 막대(반투명 · 크게 · 작게 · 복사 · 닫기).
- **고정한 캡처 관리** 창: 앞으로 가져오기, 오른쪽에 나란히, 모두 숨기기/보이기, 모두 반투명, 모두 닫기(확인 후).
- 트레이 메뉴의 자동 저장 체크가 막대의 자동저장 버튼과 항상 같게 보입니다.
