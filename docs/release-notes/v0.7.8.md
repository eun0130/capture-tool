## 캡처 도구 v0.7.8

### 새 디자인 — 캡처 버튼 막대
- 캡처 아래 버튼 막대와 그리기 도구 막대를 **어두운 둥근 막대**로 통일했습니다. 기능별로 얇은 구분선(복사 | 텍스트·표·PPT | 메일·카톡·검색 | 고정 | 전체), 메뉴도 같은 어두운 디자인입니다.

### 더 빠르게
- 영역을 고르는 순간 **글자를 미리 읽어 둡니다**. 텍스트·표·도형PPT·글자로 검색을 누르면 기다리지 않고 바로 나옵니다(보통 0.4~0.7초 빨라짐). 아주 큰 영역(약 800만 화소 이상)은 누를 때 읽습니다.

### 도형PPT — 웹 화면의 표
- 화면 속 표가 **칸마다 사각형**(테두리·머리글 색 그대로)으로 들어가고, 머리글은 자기 칸 가운데에 들어갑니다.
- 회색 버튼(확인·페이지 번호) 색이 정확하고, 버튼 안에 엉뚱한 색 조각이 생기지 않습니다.
- 제목 앞 동그라미 아이콘이 글자 "ㅇ"으로 붙지 않고 동그라미 도형으로 들어갑니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.7.8.exe`를 내려받아 실행합니다. 설정은 유지됩니다.
