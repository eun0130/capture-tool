## 캡처 도구 v0.8.18

> v0.8.17과 같은 내용 + 빌드/테스트 단계 안정화(네이티브 종료 크래시에도 릴리스가 깨지지 않도록).

### 새 기능 (전체 버튼 안)
- **인쇄**: 캡처를 프린터로. Windows 인쇄 창에서 프린터·용지를 고르고, 그림은 용지에 맞춰 들어갑니다.
- **PDF**: 캡처를 PDF로 저장. 스크롤 캡처처럼 긴 그림은 여러 쪽(A4)으로 나뉩니다(설정에서 한 쪽에 맞추기).
- **크기 줄이기**: 긴 쪽 1280px·50%·25%·용량 1MB 등으로 작게. **원본과 줄인 결과를 나란히 미리 보고** 예상 용량을 확인한 뒤 복사·저장합니다(메일·업로드용).

### 함께 포함 (v0.8.15 · v0.8.16)
- 텍스트 **줄바꿈 없이** 복사 · 도형PPT **글자를 하나의 상자로 합쳐서** · 굵은 숫자 깨짐 수정 · 띄어쓰기 자동 점검.

### 빌드 안정화
- 설치 파일 빌드가 OCR 모델 내려받기 실패로 자주 깨지던 문제를 고쳤습니다(직접 다운로드 + 재시도 + 캐시).

### 알려진 한계
- 꽉 찬 삼각형 안의 나눔선, 굵은 색 글자의 가는 대문자 I(예: "AI를"→"A를")는 글자/모양 인식 모델의 한계입니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.17.exe`를 내려받아 실행합니다.
