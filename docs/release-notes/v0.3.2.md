## 캡처 도구 v0.3.2

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 새 기능
- **글씨체 선택**: 텍스트 도구의 글씨체 상자에서 PC에 설치된 모든 글꼴을 고를 수 있습니다(이름을 입력하면 바로 찾아감).
  - 입력 중인 글자에 바로 미리 보이고, 이미 넣은 글자도 선택해서 바꿀 수 있습니다(되돌리기 가능).
  - 마지막에 쓴 글씨체를 기억해서 다음 캡처에도 사용합니다.
  - "PPT로"로 보내도 글씨체가 유지됩니다.

### 고친 문제
- 글자 크기·굵게·기울임·밑줄·취소선이 **캡처 이미지(복사·저장)에 반영되지 않던 문제**를 고쳤습니다. (v0.3.0에서는 PPT로 보낼 때만 적용되었습니다.)

### 달라진 안내
- 고정 버튼과 고정 알림에 기능 설명을 넣었습니다. 사용 가이드의 "고정" 항목도 사용 예와 함께 자세히 보강했습니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.2.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
