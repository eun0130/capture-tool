## 캡처 도구 v0.9.0

### 새 기능 — 캡처 찾기 (집용·회사용 모두)
- 저장 폴더에 쌓인 캡처를 **글자·태그·모양**으로 찾습니다. 캡처 중 **검색** → **내 캡처에서 찾기**, 트레이 메뉴 **캡처 찾기…**, 또는 설정에서 단축키.
- 저장할 때마다 태그가 저절로 붙습니다: 캡처 종류(영역/창/전체화면/스크롤/고정), 출처 앱·창 제목, 내용 종류(글/표/사진/코드/화면), 주된 색, 자주 나온 낱말. 캡처 속 글자는 PC가 한가할 때 읽어 둡니다(개인정보는 가린 뒤 저장).
- 치는 대로 결과가 바뀌고 낱말 일부만 쳐도 찾습니다("출현황" → 매출현황). 종류·내용·앱·기간·색으로 좁히고, 그림 파일을 고르거나 끌어다 놓으면 **닮은 캡처**가 가까운 순으로 나옵니다.
- 결과를 두 번 클릭하면 그 캡처가 모든 버튼(표·텍스트·PPT·그리기…)으로 다시 열립니다. 태그를 직접 붙일 수도 있습니다.
- 모든 처리는 **PC 안에서만** 됩니다. 처음 켜면 폴더에 이미 있던 그림도 한가할 때 차례로 색인합니다. 설정에서 끌 수 있습니다.

### 회사용 — 인터넷으로 나가는 기능 정리
- **웹 검색 없음**(구글 렌즈·구글·네이버·파파고), **인터넷 공유 링크 없음**(링크 버튼은 파일 링크만), **Gemini 없음**. 해당 코드가 회사용 설치본에 들어가지 않습니다.
- 번역·요약의 빠른 엔진은 **회사 AI**(사내 LLM 서버, OpenAI 호환)로 바뀌었습니다. 설정 → AI 번역·요약 → **회사 AI 서버·키 설정…** 에 서버 주소·모델·키를 넣으면 쓰고, 넣기 전에는 오프라인 AI만 씁니다. 오프라인 번역·요약은 그대로입니다.
