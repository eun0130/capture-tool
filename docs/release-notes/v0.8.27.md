## 캡처 도구 v0.8.27

### 새 기능 — 내 식대로 꾸미는 버튼 막대
- 첫 줄은 **즐겨찾기**(복사는 늘 맨 앞, 전체는 늘 맨 끝). **전체**를 누르면 나머지 버튼이 **비슷한 것끼리** — 저장 · 보내기 · 그림 손질 · 화면 — 묶여 둘째 줄에 나옵니다.
- 버튼을 **오른쪽 클릭** → 즐겨찾기에 넣기·빼기, 왼쪽·오른쪽으로, 이 장소에서 숨기기, 기본 배치로. 설정 → **버튼 막대**에서도 목록으로 고칩니다.
- **집 / 회사**: 트레이 메뉴 **지금 장소**로 바꾸면 장소마다 다른 배치를 씁니다. 회사는 기본으로 카톡이 숨겨지고 막대 끝에 **회사** 표시가 붙습니다. 편집 창의 세로 막대도 같은 순서.

### 새 기능 — 기호 도구 (S)
- 별·체크·화살표·번호·단위·손가락·날씨 등 **480여 개 기호**(글꼴에 있고 색 이모지로 바뀌지 않는 것만) 중 고르고 **클릭한 자리에 찍습니다**. 누른 채 끌면 바로 옮겨지고, 찍힌 기호를 누르면 다시 옮깁니다.
- 두 번 클릭하면 선택되어 색·크기를 바꾸고 Delete로 지웁니다. 선택한 채 다른 기호를 고르면 그 기호로 바뀝니다. 마지막 기호를 기억합니다.

### 회사용 설치 파일 (카카오톡 없음)
- `CaptureTool-Work-Setup-0.8.27.exe`: 카톡 버튼·메뉴·설명서 장·보내기 코드가 **빌드에서 빠진** 회사용. 설정으로 되살릴 수 없습니다. 장소는 늘 회사.
- 회사용은 별도 저장소 https://github.com/eun0130/capture_work/releases 에서 받습니다. 이 저장소의 설치 파일은 집용입니다.
