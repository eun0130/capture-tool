## 캡처 도구 v0.3.1

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 고친 문제
- **텍스트 도구로 여러 곳을 클릭하면 빈 입력칸이 계속 쌓이던 문제**를 고쳤습니다.
  - 입력칸이 열린 상태에서 다른 곳을 클릭하면: 글자를 안 썼으면 입력칸이 **사라지고**, 썼으면 그 글자가 **들어간 뒤** 입력칸이 닫힙니다. 그 클릭으로 새 입력칸이 생기지 않습니다(다시 클릭하면 새로 열림).
  - 입력칸은 언제나 하나만 열립니다.
  - 입력 중에 다른 도구를 고르거나, 복사·저장·텍스트·PPT로 버튼을 눌러도 쓰던 글자가 사라지지 않고 들어갑니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.3.1.exe`를 내려받아 실행합니다. 이전 버전 위에 덮어서 업데이트되고 설정은 유지됩니다.
