## 캡처 도구 v0.6.5

### 새 기능
- **영역을 고르면 바로 복사**: Ctrl+C를 누르지 않아도 영역을 고르는 순간 클립보드에 들어가 바로 Ctrl+V 할 수 있습니다. 그림을 그리면 복사본도 그린 그대로 바뀝니다. Ctrl+C·Enter도 그대로 됩니다. (설정에서 끌 수 있음)
- **카카오톡으로 보내기**: 오른쪽 **카톡** 아이콘 → 열려 있는 채팅방을 고르면 그 채팅방에 캡처가 붙여 넣어집니다. 카카오톡의 **[전송]**을 눌러야 보내집니다(자동 전송 없음). 채팅방이 없으면 카카오톡을 열어 줍니다.
- **색·글꼴 모양 그대로 / 기본 모양 선택**: 설정에서 PPT·도형·표로 보낼 때 캡처 색을 그대로 쓸지, PowerPoint 기본 모양(흰 바탕·검은 글자)으로 넣을지 고릅니다.

### 고친 문제
- **표 모양 캡처가 도형PPT에서 표가 되지 않고, 흰 글자 글상자가 쌓여 보이지 않던 문제**: 어두운 화면·칸 선 없는 표도 표로 알아봐 PowerPoint **진짜 표**로 넣습니다. 색 유지 시 머리글·본문 칸 색과 밝은 글자, 굵은 머리글까지 그대로, 기본 모양 선택 시 PowerPoint 기본 표로 들어갑니다. 표 위 제목은 글상자로.
- **텍스트 모드에서 표 모양인데 "표로 복사" 버튼이 없던 문제**: 표가 보이면 버튼이 나타납니다.
- **어두운 화면의 밝은 글자가 흰 슬라이드에서 보이지 않던 문제**: 원래 배경색과 함께 넣습니다.
