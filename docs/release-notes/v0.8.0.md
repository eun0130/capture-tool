## 캡처 도구 v0.8.0

### 터미널·콘솔의 "글자로 그린 표"도 표로
- `┌─┬─┐ │ ├─┼─┤` 같은 선 문자로 그린 표(터미널, 명령 프롬프트, AI 답변 화면)를 **표** 버튼으로 복사하면 행·열이 그대로인 표가 됩니다.
- 터미널이 긴 칸을 다음 줄로 넘긴 글은 원래 칸에 이어 붙입니다. │ 막대는 글자에 섞이지 않습니다.
- 고정폭 글꼴 때문에 "체 계 없 음"처럼 벌어진 글자는 "체계 없음"으로 띄어쓰기를 되살립니다.

### 도형PPT — 바로 보내기와 복사의 차이를 바로 알림
- PowerPoint로 바로 보내면 화면 속 표가 **고칠 수 있는 PowerPoint 표**로, 클립보드 복사(Ctrl+V)로는 **칸 상자**로 들어갑니다(클립보드가 표를 담지 못함). 어느 쪽인지 알림에 바로 나옵니다.
- 보낸 뒤에도 클립보드에는 빠짐없는 전체 내용이 남아 다른 곳에 Ctrl+V 할 수 있습니다.

### 깔끔한 업데이트
- 설치할 때 예전 버전의 프로그램 파일을 먼저 지우고 새로 넣습니다(쓰지 않는 옛 파일이 남지 않음). 설정·주소록·기록·내려받은 모델은 그대로입니다.

### 설치 / 업데이트
아래 **Assets**에서 `CaptureTool-Setup-0.8.0.exe`를 내려받아 실행합니다.
