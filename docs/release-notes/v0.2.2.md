## 캡처 도구 v0.2.2

처음 쓰시는 분은 **[사용 가이드](https://github.com/eun0130/capture-tool/blob/main/docs/USER_GUIDE.md)** 를 먼저 보세요.

### 이번 버전에서 바뀐 점
- **프랑스어·스페인어·독일어·이탈리아어·포르투갈어** 등 라틴 문자 언어의 글자 인식을 추가했습니다.
  - é, è, ç, ñ, ü, ß, ¿, ¡ 같은 글자를 정확히 읽습니다. (이전: "garçon" → "garcon", "Straße" → "StraBe")
  - 언어를 고를 필요가 없습니다. 한국어 줄은 한국어로, 라틴 문자 줄은 해당 언어로 자동 인식합니다.
- 인터넷 없이 동작하는 것은 그대로입니다.

### 설치 / 업데이트
1. 아래 **Assets**에서 `CaptureTool-Setup-0.2.2.exe`를 내려받아 실행합니다. 이전 버전이 있으면 덮어서 업데이트되고 설정은 유지됩니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.

### 요구 사항
Windows 10(1809 이상) / 11, 64비트 · 약 360MB · "PPT로"는 PowerPoint(Microsoft 365 권장) 필요
