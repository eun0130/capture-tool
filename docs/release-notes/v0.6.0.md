## 캡처 도구 v0.6.0

### 새 기능 — 캡처 편집 창
- **스크롤 캡처와 창 전체 캡처(여러 모니터에 걸친 창)가 끝나면 큰 편집 창이 열립니다.** 예전에는 Ctrl+V로 붙여넣기만 할 수 있었는데, 이제 일반 캡처와 똑같이 쓸 수 있습니다.
  - 그리기 도구와 색상 팔레트(사각형·화살표·글자·형광펜·모자이크·자유형 자르기 등)
  - 텍스트(글자 인식, 드래그 부분 복사, 번역·요약), PPT로, 도형PPT, 링크, 고정, 저장
  - 확대/축소: Ctrl+휠, 축소·확대·100%·폭 맞춤 버튼. 처음엔 실제 크기로 크게 보입니다.
- 자동 저장이 켜져 있으면 캡처할 때 바로 저장되고, 편집 창에서 그린 내용이 있으면 **같은 파일에** 반영됩니다(파일이 두 개 생기지 않음).

### 고친 문제
- **긴 그림·4K 화면에서 글자 인식이 깨지던 문제**: 글자 인식 엔진이 2000픽셀보다 큰 그림을 자동으로 줄여서 글자가 뭉개졌습니다. 이제 큰 그림은 겹치게 나눠서 원래 크기로 인식합니다(7000픽셀 높이 페이지에서 모든 줄 인식 확인).
- 모자이크를 칠할 때 큰 그림에서 화면이 느려지던 문제(모자이크 부분만 다시 그림).
- 아주 긴 그림을 고정하면 화면 밖으로 넘치던 문제(화면에 맞게 줄여 붙임).
